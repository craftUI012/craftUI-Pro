## Issues

| #   | Issue                                                    | Status | Notes                                                                                                                                                                    |
| --- | -------------------------------------------------------- | ------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 1   | `components.json` pointed to `app/globals.css`           | Fixed  | Now `styles/globals.css`                                                                                                                                                 |
| 2   | Two lockfiles (`package-lock.json` + pnpm)               | Fixed  | `package-lock.json` removed. `packageManager: pnpm@10.28.2` added, and CI reads the version from it.                                                                     |
| 3   | `app/llms.txt/route.ts` failed `tsc`                     | Fixed  | `llms(source).index()` returns a Promise in the installed fumadocs-core. The route is now async.                                                                         |
| 4   | `registry.json` had no `$schema`                         | Fixed  | Added                                                                                                                                                                    |
| 5   | `CONTRIBUTING.md` belonged to another project            | Fixed  | Rewritten for craftUI Pro                                                                                                                                                |
| 6   | `examples/` folder missing                               | Open   | Not a bug: create `examples/<name>.tsx` when you want demo-specific preview source                                                                                       |
| 7   | Colour themes not mounted                                | Open   | See [Theming and styles](/docs-admin/guides/theming-and-styles)                                                                                                          |
| 8   | Client components used the fallback domain in production | Fixed  | Server-only variables are invisible in the browser. The domain now comes from `NEXT_PUBLIC_SITE_URL`, which both can read. The unused `NEXT_PUBLIC_API_URL` was removed. |
