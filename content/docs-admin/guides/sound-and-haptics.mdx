## Pieces

| Piece       | File                                                      | Role                                                                                                |
| ----------- | --------------------------------------------------------- | --------------------------------------------------------------------------------------------------- |
| Sound pack  | `audio/core.ts`, `audio/index.ts`                         | Generated by the `@web-kits/audio` CLI (config in `.web-kits/config.json`). **Don't edit by hand.** |
| Provider    | `app/layout.tsx`                                          | `<SoundProvider>` from `@web-kits/audio/react` wraps the app                                        |
| Hook        | `hooks/use-feedback.ts`                                   | `useFeedback({ sound, soundDef, haptic })` returns a function that plays the sound and haptic       |
| Toggles     | `hooks/use-sound-toggle.ts`, `hooks/use-haptic-toggle.ts` | jotai atoms in `localStorage` (`sound-enabled`, `haptics-enabled`), both **off by default**         |
| Settings UI | `components/site-settings.tsx`                            | Gear icon in the header, ⌘S or Ctrl+S                                                               |

## Using it

Many primitives in `components/ui/` accept a `sound` prop:

```tsx
<Button sound="click">Save</Button>
<TabsTrigger sound="tabSwitch" value="pnpm">pnpm</TabsTrigger>
```

In your own client component:

```tsx
"use client";
import { useFeedback } from "@/hooks/use-feedback";

const play = useFeedback({ sound: "success" });
// later: play();
```

## Sound names

The type `FeedbackType` is the camel-cased version of every key in `audio._patch.sounds`, for example `click`, `tap`, `toggleOn`, `toggleOff`, `success`, `error`, `copy`, `tabSwitch`, `modalOpen`, `drawerClose`, `pageEnter` and `notification`. Your editor will autocomplete them.

## Haptics

`hapticPresetByType` in `use-feedback.ts` maps some sounds to a `web-haptics` preset (for example `click` to `medium`, `success` to `success`, `copy` to `selection`). Sounds without a mapping play no vibration. Pass `haptic: false` to turn it off for a single call.

<Callout title="Site-only">
  The feedback system is part of **this website**. Don't import `useFeedback`
  inside `registry/new-york/*` components. Users installing them won't have it.
</Callout>
