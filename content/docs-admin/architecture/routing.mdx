## Pages

| URL                            | File                                        | Rendering                                                   |
| ------------------------------ | ------------------------------------------- | ----------------------------------------------------------- |
| `/`                            | `app/(app)/(root)/page.tsx`                 | static                                                      |
| `/docs`, `/docs/*`             | `app/(app)/docs/[[...slug]]/page.tsx`       | static, one page per MDX file                               |
| `/docs-admin`, `/docs-admin/*` | `app/(app)/docs-admin/[[...slug]]/page.tsx` | static, only when `environment=development` (otherwise 404) |

## Proxy (`proxy.ts`)

Next.js 16 renamed `middleware.ts` to `proxy.ts`. This one does **markdown content negotiation** using `fumadocs-core/negotiation`:

| Incoming request                         | Rewritten to                   |
| ---------------------------------------- | ------------------------------ |
| `GET /` with `Accept: text/markdown`     | `/llms.md/content.md`          |
| `/docs/foo.md` (any `Accept`)            | `/llms.md/docs/foo/content.md` |
| `/docs/foo` with `Accept: text/markdown` | `/llms.md/docs/foo/content.md` |

It's a **rewrite**, so the browser URL stays the same.

## Redirects (`next.config.mjs`)

- `/docs.mdx` goes to `/docs.md` (permanent)
- `/docs/:path*.mdx` goes to `/docs/:path*.md` (permanent)

## Headers (`next.config.mjs`)

`/` responds with a `Link` header that advertises the API catalog, the OpenAPI description, the docs, the shadcn MCP docs and the agent skills index. This is for agent discovery.

## Adding a new route

1. Add the path to `ROUTES` in `constants/routes.ts`.
2. Create the folder under `app/(app)/` if it needs the header and footer, or directly under `app/` if it doesn't.
3. If it should appear in the navbar, add it to `navItems` in `components/site-header.tsx`. That list also feeds `MobileNav` and `CommandMenu`.
4. If it's public, add it to `app/sitemap.ts`.
