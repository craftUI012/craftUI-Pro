**craftUI Pro** is a collection of crafted React components built on top of [shadcn/ui](https://ui.shadcn.com). Every component is distributed through a [shadcn registry](https://ui.shadcn.com/docs/registry), so you install it with the shadcn CLI and the source code lands directly in your project.

## Why craftUI Pro

- **You own the code.** Components are copied into your project, not hidden inside a package. Change anything.
- **Works with your theme.** Components use shadcn's CSS variables (`bg-primary`, `text-muted-foreground` and so on), so they pick up your existing colours, radius and dark mode.
- **One command to install.** `npx shadcn add` installs the component, its npm dependencies and any shadcn primitives it needs.
- **Built with** React 19, TypeScript and Tailwind CSS v4.

## How it works

1. Set up shadcn/ui in your project (see [Installation](/docs/installation)).
2. Pick a component from the [Components](/docs/components) page.
3. Run its install command:

<InstallCommand name="<component>" />

4. Import it from your components folder and use it.
